# KZ Support Reference

KZ Support Reference is a portable IT support reference for PowerShell commands, Windows troubleshooting, hardware support, maintenance notes, scripts, and technical study notes.

## Current Stage

This is the initial static project structure. The current page provides a simple responsive landing view with placeholder reference categories and basic category filtering.

## Technologies

- HTML
- CSS
- Vanilla JavaScript

There are no frameworks, build tools, backend services, databases, package managers, or runtime dependencies.

## Offline and Portable Goal

The project is intended to work offline from a local folder or USB drive. It uses relative paths only and can be opened directly with `file:///`.

## How to Open

Open `index.html` in a web browser.

## Future Direction

Future updates can add detailed reference pages, command examples, troubleshooting checklists, scripts, notes, and richer search behavior while keeping the project lightweight and portable.
