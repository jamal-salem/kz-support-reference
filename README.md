# KZ Support Reference

KZ Support Reference is a portable IT support reference for PowerShell commands, Windows troubleshooting, hardware support, maintenance notes, scripts, and technical study notes.

## Current Stage

This is an early static reference project. The home page provides searchable support categories, and the first real knowledge section is `Hardware -> Cables`.

## Technologies

- HTML
- CSS
- Vanilla JavaScript

There are no frameworks, build tools, backend services, databases, package managers, or runtime dependencies.

## Offline and Portable Goal

The project is intended to work offline from a local folder or USB drive. It uses relative paths only and can be opened directly with `file:///`.

## How to Open

Open `index.html` in a web browser.

Current navigation path:

- `index.html`
- `hardware/index.html`
- `hardware/cables/index.html`

## Future Direction

Future updates can add detailed reference pages, command examples, troubleshooting checklists, scripts, notes, report structures, and richer search behavior while keeping the project lightweight and portable.
